# Nested archive reference coverage

The coverage audit found 265 crafting enhancement pages, 56 class reference
subpages, and five event index/reference pages omitted by the depth-limited
route matcher. Parser version 17 queues these canonical public routes as source
pages, preserving metadata and links with an explicit typed-extraction gap.
They do not become guessed items, classes, abilities or quests.

Class trainer, recipe and diplomacy card detail parsing remains distinct.
Query URLs, fragments, external URLs and deeper unexpected routes remain
excluded. Earlier delivered batches remain immutable.

Offline regression checks cover route inclusion, source-only parsing and query
exclusion. Full typed fact extraction from these reference pages remains pending.
